# 🌸 Mi pequeño universo — regalo romántico

Proyecto web 3D hecho con HTML, CSS, JavaScript y Three.js.

## Qué incluye

- Escena 3D interactiva.
- Flores flotando y orbitando.
- Estrellas y partículas.
- Frases románticas que cambian.
- Controles táctiles para celular.
- Pantalla inicial.
- Mensaje final.
- Botón para recentrar la cámara.
- Todo funciona desde un navegador.

## Estructura

- `index.html` — estructura de la página.
- `style.css` — diseño y animaciones.
- `script.js` — escena 3D e interacción.

## Cómo probarlo

Por usar módulos JavaScript, lo recomendable es abrirlo mediante un servidor local.

Si tenés VS Code:
1. Instalá la extensión "Live Server".
2. Abrí la carpeta.
3. Clic derecho sobre `index.html`.
4. Elegí "Open with Live Server".

También podés subir directamente los archivos a un servicio de hosting estático como Vercel o GitHub Pages.

## Personalización

En `script.js`, buscá:

`const phrases = [...]`

Ahí podés cambiar todas las frases.

En `index.html` podés cambiar:
- "Mi pequeño universo"
- el mensaje inicial
- el mensaje final
- la firma "EXI ❤️"

No hace falta instalar Three.js: el proyecto usa una versión desde CDN.
